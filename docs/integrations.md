# Integrations and evidence boundaries

## Subscription adapter

The Codex app-server adapter is application integration glue. It can execute a separately approved bounded subscription task under an exact profile and one-use gate; it is not the native Agents SDK model backend. The platform records provenance and keeps unavailable token, cost and quota values unknown. No automatic fallback or replay follows a failed or uncertain attempt.

A retained observation dated 2026-11-03 reports one separately authorized synthetic text brief through the console and adapter, followed by reopening its recorded result after a normal runtime restart. This is a historical, single-turn result; it does not establish arbitrary tool use, remote cancellation, billing, power-loss recovery or native SDK model execution. Another historical fixed synthetic review succeeded under a separate grant. A later native turn candidate encountered an unexpected notification and stopped; compatibility was not established. Grants were specific and consumed. The newer local evidence may not be present in the published component repositories.

## MCP and sample

The independent MCP service exposes synthetic echo, sample lookup and controlled failure tools. Local stdio and streamable HTTP are integration boundaries; a transport test is not production authorization or proof of external side-effect safety. The sample service intentionally contains a pricing defect. Copy it into a disposable workspace for review or repair and use its independent validation to distinguish a known expected failure from a repaired target.

## Sandbox and external systems

Controlled container experiments are finite and separately scoped. Native local execution alone must not be assumed to confine untrusted code. Docker is optional for ordinary offline work; service grouping is not a scheduler. Production providers, hosted capabilities and real external systems require their own setup, privacy review and explicit authorization. No credential values belong in documentation or version control.
